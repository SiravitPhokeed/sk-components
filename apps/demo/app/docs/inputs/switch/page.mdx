## Switch

A Switch toggles something on and off. It is usually in a Form Item. Unlike
Checkbox and Radio, a Switch is independent.

<Switch />

### Usage

Use [Form Item](/docs/inputs/form-item) to add a label to a Switch.

```tsx
const [allow, setAllow] = useState(false);

return (
  <FormItem label="Allow notifications">
    <Switch value={allow} onChange={setAllow} />
  </FormItem>
);
```

When using a Switch without Form Item, provide an `alt` so assistive
technologies can identify it.

```tsx
<Switch alt="Dark mode" />
```

### Props

- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="alt" required="conditional">
    <TableCell>`string`</TableCell>
    <TableCell>

      A description of the Switch for screen readers, similar to `alt` on
      `<img>`.

      - Set this when using a Switch without Form Item, so the Switch still has
        an accessible name for assistive technologies.
      - Optional if inside a Form Item.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="name" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The name of the Switch, used for form submission. If not provided, falls
      back to the parent Form Item’s `name`.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="value" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      The state of the Switch. This is useful if you want a controlled input.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onChange" required="never">
    <TableCell>`(value: boolean) => any`</TableCell>
    <TableCell>

      Called when the user toggles the Switch. The state is passed in via the
      function as a boolean.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="offIcon" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon inside the thumb when the Switch is off.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as
        the value for `offIcon`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onIcon" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon inside the thumb when the Switch is on.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as
        the value for `onIcon`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Turns the Switch gray and blocks any action associated with it.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
