## Form Item

A wrapper for form control components like Checkbox, Radio, and Switch with
a label.

<LinksChipSet source="/FormItem.tsx" />

<DemoCard
  component={FormItem}
  initialProps={{
    children: <Switch />,
    label: "Dark mode",
  }}
/>

```tsx
<FormItem label="Dark mode">
  <Switch />
</FormItem>
```

### Props

- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

  <PropsTableRow prop="children" required="always">

      - Always required.
