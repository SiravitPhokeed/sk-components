## Radio

A choice from a single-select set of choices. Unlike Checkbox and Switch,
Radio always appears in a group.

### Props

- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

<PropsTable>
  <PropsTableRow prop="value" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      The state of the Radio. This is useful if you want a controlled input.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onChange" required="never">
    <TableCell>`(value: boolean) => any`</TableCell>
    <TableCell>

      This function triggers when the user toggles the Radio. The state is
      passed in via the function as a boolean.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      - Optional.

      </TableCell>

  </PropsTableRow>
