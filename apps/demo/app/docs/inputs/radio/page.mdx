## Radio

A choice from a single-select set of choices. Unlike Checkbox and Switch,
Radio always appears in a group.

### Usage

Radio always appears in a group. Use [Form Group](/docs/inputs/form-group) to
group related Radios and [Form Item](/docs/inputs/form-item) to label each one.

#### Uncontrolled Radio

Set `name` on the Form Group and give each Radio a `value`. The browser handles
making sure only one Radio is selected at a time. Read the selected value with
[`FormData`](https://developer.mozilla.org/en-US/docs/Web/API/FormData) on
submit.

```tsx
<form
  onSubmit={(e) => {
    e.preventDefault();
    const formData = new FormData(e.currentTarget);
    console.log(formData.get("atk-result")); // "negative" or "positive"
  }}
>
  <FormGroup name="atk-result" label="ATK result">
    <FormItem label="Negative">
      <Radio value="negative" />
    </FormItem>
    <FormItem label="Positive">
      <Radio value="positive" />
    </FormItem>
  </FormGroup>
  <Button type="submit">Submit</Button>
</form>
```

#### Controlled Radio

Manage the selected value with `useState`. Use `checked` to indicate which Radio
is selected and `onChange` to update the state.

```tsx
const [atkResult, setATKResult] = useState<"negative" | "positive">();

return (
  <FormGroup name="atk-result" label="ATK result">
    <FormItem label="Negative">
      <Radio
        value="negative"
        checked={atkResult === "negative"}
        onChange={setATKResult}
      />
    </FormItem>
    <FormItem label="Positive">
      <Radio
        value="positive"
        checked={atkResult === "positive"}
        onChange={setATKResult}
      />
    </FormItem>
  </FormGroup>
);
```

### Props

- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="name" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The name of the Radio, used to group Radios together for form submission.
      If not provided, falls back to the parent Form Item’s `name`, then
      the parent Form Group’s `name`.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="value" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The value submitted when this Radio is selected, similar to `value` on
      `<input type="radio">`. Defaults to `on`.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="checked" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Whether the Radio is selected. This is useful if you want a controlled
      input.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onChange" required="never">
    <TableCell>`(value: string) => any`</TableCell>
    <TableCell>

      Called when the user selects the Radio. The value is passed in via the
      function.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Turns the Radio gray and blocks any action associated with it.

      - [Learn how to make disabled elements less frustrating.](/docs/guides/disabling-elements)
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
