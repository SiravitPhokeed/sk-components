## Text Field

A field where users enter text — from short passwords to long-form
answers.

### Props

- `StyleableProps` are available: `className` and `style`.

<PropsTable>
  <PropsTableRow prop="appearance" required="always">
    <TableCell>
      ```
      "outlined"
      | "filled"
      ```
    </TableCell>
    <TableCell>

      How the Text Field looks. An outlined Text Field has a lower emphasis than
      filled, so it is great for a form with many fields.

      - Keep the appearance consistent across Text Fields. Separate different
        appearances by region.
      - Must be `outlined` or `filled`.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="label" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The placeholder text (when not focused and no value) and the label text
      (when focused or has value).

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="type" required="never">
    <TableCell>
      ```
      "color"
      | "date"
      | "datetime-local"
      | "email"
      | "file"
      | "month"
      | "number"
      | "password"
      | "search"
      | "tel"
      | "text"
      | "time"
      | "url"
      | "week"
      ```
    </TableCell>
    <TableCell>
    
      The type of the input field. This is useful if you want a specialized input
      field, like a date picker or a color picker.

      - Optional. Defaults to `text`.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="behavior" required="never">
    <TableCell>
      ```
      "single-line"
      | "multi-line"
      | "textarea"
      ```
    </TableCell>
    <TableCell>

      How the Text Field behaves if the field value exceeds the visual space.

      - A single line Text Field can only accommodate 1 line of text. Field value
        never wraps and instead scrolls.
      - A multi-line Text Field starts with just accommodating 1 line but
        vertically extends to fit the field value as needed.
      - A text area Text Field has a fixed height and wraps text.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="align" required="never">
    <TableCell>
      ```
      "left"
      | "right"
      ```
    </TableCell>
    <TableCell>

      The alignment of the input field.

      - This is useful if the input value should come immediately before the
        trailing text, like the start of an email.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="leading" required="never">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The leading text or icon, aligned to the left.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="trailing" required="never">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The trailing text or icon, aligned to the right.

      - Incompatible with `canClear`, as that requires the space of the trailing
        icon for the clear button.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="helperMsg" required="conditional">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      A short description of the Text Field, or an error message during an error
      state.

      - Optional but recommended during an error state.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="required" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      If the user has to enter text in this field for the form to be valid.

      - Activates the error state after the user exits the Text Field without
        entering anything, even if `error` is false.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Turns the Text Field gray and blocks user input. `onChange` will not fire.

      - [Learn when to disable something.](https://codium.one/index.php/en/blog/77-disabled-buttons-don-t-have-to-suck)
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="error" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Tells Text Field that it contains an invalid value and activates the error
      state.

      - Browser validation may override this if the field value is invalid, even
        if `error` is false.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="value" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The value inside the field. This is useful if you want a controlled input.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="conditional">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the “No files attached” text, which is put in
      place of the file name when no files have been attached yet.

      - Only valid if `type` is `file`.
      - Must be `th` or `en-US`, SKCom supports two languages: th and en-US.
        languages.
      - Optional.

    </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onChange" required="never">
    <TableCell>`(value: Value) => any`</TableCell>
    <TableCell>

      This function triggers when the user makes changes to the field value. The
      value is passed in via the function.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="inputAttr" required="never">
    <TableCell>`ComponentProps<"input">`</TableCell>
    <TableCell>

      Attributes for the underlying `<input>` element used as the field.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>

  <VersionsTableRow version="v3.0.2">
    Generic type parameter introduced.
  </VersionsTableRow>
  <VersionsTableRow version="v3.0.0">
    Rewritten as Text Field, merging Input and Text Area.
  </VersionsTableRow>
  <VersionsTableRow version="v2.6.0">
    Required field indicator and manual error state class added.
  </VersionsTableRow>
  <VersionsTableRow version="v2.5.0">
    React implementation introduced (as Input).
  </VersionsTableRow>
  <VersionsTableRow version="v2.4.2">
    Error indicator, error message, and helper message added.
  </VersionsTableRow>
  <VersionsTableRow version="v2.0.0">
    Input rewritten with Persistent and Dropdown variants.
  </VersionsTableRow>
  <VersionsTableRow version="v1.0.0">
    Input introduced (predecessor to Text Field).
  </VersionsTableRow>
</VersionsTable>
