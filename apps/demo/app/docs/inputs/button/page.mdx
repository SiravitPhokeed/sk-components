## Button

Button helps users take action, whether it’s logging in, liking a post, or going to a page.

```tsx
<Button appearance="filled" icon={<MaterialIcon icon="person_add" />}>
  Add friend
</Button>
```

### Usage

**Use the right appearance for the right priority.** Button has 4 appearances,
from highest to lowest priority: `filled`, `tonal`, `outlined`, and `text`. For
example, in a log in page, the log in Button has higher priority than the
password recovery button. In this case, the log in Button is “filled,” and the
password recovery is “text.”

<Actions align="left" className="mt-3 mb-6">
  <Button children="Log in" appearance="filled" />
  <Button children="Forgot password" appearance="text" />
</Actions>

**Choose appearances that are easy to distinguish.** A set of tonal Buttons or
text Buttons can blend together, making it hard for users to distinguish them.
Use a mix of appearances to make it easier for users to identify the Buttons.

<div className="flex items-center gap-1 px-2">
  <MaterialIcon icon="cancel" size={20} className="text-error" />
  <Text type="title-small" className="text-on-surface-variant">
    Don’t
  </Text>
</div>
<Actions align="left" className="mb-6">
  <Button children="Yes" appearance="text" />
  <Button children="No" appearance="text" />
  <Button children="Maybe" appearance="text" />
</Actions>

**Use “Sentence case”** instead of “Title Case” or a “CAPS BLOCK” for the text
in Button.

<Actions align="left" className="mt-3 mb-6">
  <Button
    children="Add friend"
    appearance="outlined"
    icon={<MaterialIcon icon="check_circle" />}
  />
  <Button
    children="Add Friend"
    appearance="outlined"
    icon={<MaterialIcon icon="cancel" />}
    dangerous
  />
  <Button
    children="ADD FRIEND"
    appearance="outlined"
    icon={<MaterialIcon icon="cancel" />}
    dangerous
  />
</Actions>

**[Actions](/docs/inputs/actions) can be used to group Buttons together.**

### Props

- [`ActionableProps`](/docs/guides/shared-props) available: `command`,
  `commandfor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.

  <PropsTableRow prop="children" required="conditional">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>
      
      The text displayed inside the Button.

      - Must be a React Node, e.g., a string or an element.
      - Required if `icon` is undefined, as a Button cannot be empty.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="appearance" required="always">
    <TableCell>
      ```
      "filled"
      | "tonal"
      | "outlined"
      | "text"
      ```
    </TableCell>
    <TableCell>

      <Actions align="left">
        {["filled", "tonal", "outlined", "text"].map((appearance) => (
          <Button
            key={appearance}
            children="Button"
            appearance={appearance}
          />
        ))}
      </Actions>

      The appearance of the Button.

      Each appearance has a priority. For example, in a log in page, the log in
      button has higher priority than the password recovery Button. In this
      case, the log in Button is “filled,” and the password recovery is “text.”

      - Must be `filled`, `tonal`, `outlined`, or `text`, from highest to lowest
        priority.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="icon" required="conditional">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>
      
      An icon can appear before the text (`children`) in a Button. In a page
      with many buttons, icons can quickly orient users.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as
        the value for `icon`.
      - Normally optional but required if `children` is undefined, as a Button
        cannot be empty.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="alt" required="conditional">
    <TableCell>`string`</TableCell>
    <TableCell>
      
      A description of the Button for screen readers, similar to `alt` on
      `<img>`.

      - Required if the Button just includes `icon`, because an icon has no
        significance for screen readers.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="tooltip" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>
      
      A message shown in a tooltip when the user hovers over the Button.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="autoFocus" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>
      
      If the Button is focused when the page loads.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="selected" required="conditional">
    <TableCell>`boolean`</TableCell>
    <TableCell>
      
      If the Button is selected. `icon` is replaced with a checkmark if this is
      true.

      - **Important:** this is intended to be used only when the Button is
        inside a [Segmented Button](/docs/inputs/segmented-button). This prop will still be functional otherwise,
        but it is against Material guidelines.
      - Required when inside a Segmented Button.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="dangerous" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      <Button children="Button" appearance="outlined" dangerous />

      If the action the Button accomplishes is dangerous, like deleting your
      account. If it is, the Button turns red (defined as `error` in the
      palette).

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="loading" required="never">
    <TableCell>`boolean | number`</TableCell>
    <TableCell>

      <Button children="Button" appearance="outlined" loading />

      Disable the Button and add a Progress spinner in front of the text to
      signify loading status. `onClick` and `href` will have no effect.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      <Button children="Button" appearance="outlined" disabled />

      Turns the Button gray and blocks any action associated with it. `onClick`
      and `href` will have no effect.

      - [Learn how to make disabled elements less frustrating.](/docs/guides/disabling-elements)
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>
      
      Allows for translation of the accessibility labels.

      - Must be `en-US` or `th`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="type" required="never">
    <TableCell>
      ```
      "submit"
      | "reset"
      | "button"
      ```
    </TableCell>
    <TableCell>
      
      The type of the Button, similar to `type` on `<button>`.

      - Must be `submit`, `reset`, or `button`.
      - Optional. Defaults to `button`.

      </TableCell>

  </PropsTableRow>
</PropsTable>
