## Chip Field

A combination of Input Chips and a Text Field. Users can simply start typing
into the Chip Field; their input is converted into an Input Chip on spacebar
press.

### Usage

Here is how you can use Chip Field in your React application, using `useState`
to manage the state of the Input Chips.

```tsx
const ColorChipField = () => {
  const [colors, setColors] = useState<string[]>([]);

  const addColors = (newColors: string[]) => {
    setColors((prev) => [...prev, ...newColors]);
  };
  const removeColor = (color: string) => {
    setColors((prev) => prev.filter((c) => c !== color));
  };
  const removeLastColor = () => {
    setColors((prev) => prev.slice(0, -1));
  };

  return (
    <ChipField
      label="Colors"
      onNewEntries={addColors}
      onDeleteLast={removeLastColor}
    >
      <ChipSet>
        {colors.map((color) => (
          <InputChip key={color} onDelete={() => removeColor(color)}>
            {color}
          </InputChip>
        ))}
      </ChipSet>
    </ChipField>
  );
};
```

This gives you the freedom to implement your own logic for how Input Chips are
added and removed.

For example, you may want to fetch a list of colors from an
API and only allow the user to add colors that are in that list, or you may want
to limit the number of Input Chips that can be added.
