## Segmented Button

Segmented Button combines multiple related Buttons together. Each Button in
a Segmented Button can be toggled on and off.

<DemoCard
  component={SegmentedButton}
  initialProps={{
    children: [
      <Button key="schedule" appearance="outlined" selected>
        Schedule view
      </Button>,
      <Button key="subject" appearance="outlined">
        Subject view
      </Button>,
    ],
    alt: "View options",
    className: "w-full justify-center",
  }}
  adjustableProps={{
    full: "boolean",
  }}
/>

```tsx
<SegmentedButton alt="View options">
  <Button appearance="filled" selected>
    Schedule view
  </Button>
  <Button appearance="tonal">Subject view</Button>
</SegmentedButton>
```
