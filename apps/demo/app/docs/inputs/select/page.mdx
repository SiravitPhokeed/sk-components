## Select

Sometimes it’s impractical to show all options at a time with a radio group.
Select allows the user to choose from options that appear in a dropdown
menu.

### Usage

Manage the selected value with `useState`. Each option is a
[Menu Item](/docs/overlays/menu-item) with a `value`.

```tsx
type Frequency = "one-off" | "daily" | "weekly";

const [frequency, setFrequency] = useState<Frequency>();

return (
  <Select<Frequency>
    appearance="outlined"
    label="Frequency"
    value={frequency}
    onChange={setFrequency}
  >
    <MenuItem value="one-off">One-off</MenuItem>
    <MenuItem value="daily">Daily</MenuItem>
    <MenuItem value="weekly">Weekly</MenuItem>
  </Select>
);
```

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

      "outlined"
      | "filled"

    <TableCell>

      How the Select looks. An outlined Select has a lower emphasis than filled,
      so it is great for a form with many fields.

      - Keep the appearance consistent across Selects. For example, use `outlined`

        in the same context.
      - Must be `outlined` or `filled`.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="label" required="always">

      </TableCell>

  <PropsTableRow prop="leading" required="never">
