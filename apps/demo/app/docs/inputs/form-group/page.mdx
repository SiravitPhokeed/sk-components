## Form Group

A group of related Form Items, like options in a radio group.

<LinksChipSet source="/FormGroup.tsx" />

<DemoCard
  component={FormGroup}
  initialProps={{
    children: [
      <FormItem key="email" label="Email">
        <Checkbox />
      </FormItem>,
      <FormItem key="sms" label="SMS">
        <Checkbox />
      </FormItem>,
    ],
    label: "Receive notifications via",
  }}
/>

```tsx
<FormGroup label="Receive notifications via">
  <FormItem label="Email">
    <Checkbox />
  </FormItem>
  <FormItem label="SMS">
    <Checkbox />
  </FormItem>
</FormGroup>
```

### Props

- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      Form Items within this group, be it a set of options to choose from or
      related settings in a preferences page.

      - Must only be Form Items.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="name" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The name for the form group, passed down to form controls like Radio via
      context. If not provided, a random name is generated.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="label" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The legend for the entire group.

      - Must be a React Node, e.g., a string or an element.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="legendElement" required="never">
    <TableCell>`ElementType`</TableCell>
    <TableCell>

      The HTML element to render for the `<legend>`. Defaults to `"label"`.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
