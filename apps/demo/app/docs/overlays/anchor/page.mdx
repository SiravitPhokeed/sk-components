## Anchor

Associates a trigger element (e.g. a Button) with a positioned element (e.g.
a Menu) using CSS Anchor Positioning.

> On the <MaterialIcon icon="do_not_disturb_on" size={20} className="inline-block -mb-1 -rotate-45" />
> partial support tier, positioned elements appear as bottom sheets instead of
> floating next to their trigger. Read the [browser support guide](/docs/guides/browser-support)
> for more details.

### Usage

The **implicit pattern** is the recommended way to use Anchor.

- Put the trigger element (e.g. a [Button](/docs/inputs/button)) and the
  positioned element (e.g. a [Menu](/docs/overlays/menu)) inside an Anchor.

```tsx
<Anchor>
  <Button appearance="filled" command="show-popover" commandfor="share-menu">
    Share
  </Button>
  <Menu id="share-menu">
    <MenuItem icon={<MaterialIcon icon="email" />}>Email</MenuItem>
    <MenuItem icon={<MaterialIcon icon="chat" />}>Messages</MenuItem>
  </Menu>
</Anchor>
```

The **explicit pattern** is useful when the
trigger and positioned elements are not adjacent in the DOM.

- Wrap the trigger element in an Anchor and give it a `name` prop
  (dashed-ident).
- Give the positioned element an `anchor` prop with the same value as the Anchor’s
  `name` prop.

```tsx
<Anchor name="--share-menu-anchor">
  <Button appearance="filled" command="show-popover" commandfor="share-menu">
    Share
  </Button>
</Anchor>
<Menu id="share-menu" anchor="--share-menu-anchor">
  <MenuItem icon={<MaterialIcon icon="email" />}>Email</MenuItem>
  <MenuItem icon={<MaterialIcon icon="chat" />}>Messages</MenuItem>
</Menu>
```

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      Elements to anchor together — typically a trigger element (e.g. a Button)
      followed by the positioned element (e.g. a Menu).

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="name" required="never">
    <TableCell>`--{string}`</TableCell>
    <TableCell>

      The anchor name (dashed-ident) used for CSS Anchor Positioning.

      - Optional. Auto-generated if omitted.
      - When using the explicit pattern (Anchor wraps trigger only, Menu
        positioned elsewhere), set this explicitly and pass the same value
        to the Menu’s `anchor` prop.
      - Must be a valid dashed-ident (e.g. `--menu-trigger`).

      </TableCell>

  </PropsTableRow>
</PropsTable>
