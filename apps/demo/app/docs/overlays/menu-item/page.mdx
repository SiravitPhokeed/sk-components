## Menu Item

An action/option inside a temporary list.

```tsx
<MenuItem
  icon={<MaterialIcon icon="content_copy" />}

  command="hide-popover"
>
  Copy
</MenuItem>
```

### Usage

Menu Items are used inside Menu and Select. If not provided, `commandfor` will
default to the nearest Menu’s `id`.

### Props

- [`ActionableProps`](/docs/guides/shared-props): `command`, `commandfor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

      - If one Menu Item in a Menu has an icon, the rest should have one too.

      - Optional.

      </TableCell>

    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      A message shown in a tooltip when the user hovers over the Menu Item.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="selected" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="dangerous" required="never">
    <TableCell>`boolean`</TableCell>

      If the action the Menu Item accomplishes is dangerous, like deleting your

      palette).

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>

      - [Learn how to make disabled elements less frustrating.](/docs/guides/disabling-elements)
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="value" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The value of a Select item, similar to `value` on `<option>`.

      - **Important:** this is intended to be used only when the Menu Item is
        inside a Select. This prop is not functional otherwise.
      - Optional.

      </TableCell>

  </PropsTableRow>
