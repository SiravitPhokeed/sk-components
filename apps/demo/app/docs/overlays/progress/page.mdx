## Progress

A Progress indicates that something is ongoing. It can also indicate how
much of that something has been done.

<Progress appearance="linear" alt="Loading…" />

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="appearance" required="always">
    <TableCell>
      ```
      "linear"
      | "circular"
      ```
    </TableCell>
    <TableCell>

      Progress can be either a loading spinner or a linear loading bar.

      - Must be `linear` or `circular`.
      - Keep the appearance consistent for the same actions. For example, if
        loading a post uses `linear` in one place, the same action should always
        use `linear` elsewhere.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="alt" required="always">
    <TableCell>`string`</TableCell>
    <TableCell>

      A description of the Progress for screen readers, similar to `alt` on
      `<img>`.

      - Always required, because a Progress has no significance to screen readers.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="value" required="never">
    <TableCell>`number`</TableCell>
    <TableCell>

      <div className="flex flex-row gap-2 mb-4">
        <Progress appearance="circular" alt="Determinate" value={60} />
        <Progress appearance="circular" alt="Indeterminate" />
      </div>

      The progress percentage of an activity (a value from 0 to 100).

      - If undefined, the Progress will be in an indeterminate state.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="visible" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Whether this Progress is rendered. Set to `false` to unmount it entirely.

      - Optional. Defaults to rendered.

      </TableCell>

  </PropsTableRow>
</PropsTable>
