## Migrating to v3.3

- `useAnimationConfig()` is now deprecated. Use the `DURATION` and `EASING` constants instead.

```tsx
// Before
import { transition, useAnimationConfig } from "@suankularb-components/react";
const { duration, easing } = useAnimationConfig();
transition(duration.short4, easing.standard);

// After
import { DURATION, EASING, transition } from "@suankularb-components/react";
transition(DURATION.short4, EASING.standard);
```

v3.3 was released on April 8, 2024. See the [release notes](https://github.com/suankularb-wittayalai-school/sk-components/pull/131) for more information.
