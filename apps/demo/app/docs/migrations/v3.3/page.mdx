## Migrating to v3.3

v3.3 was released on April 8, 2024. See the
[release notes](https://github.com/suankularb-wittayalai-school/sk-components/pull/131)
for more information.

```bash
npm install @suankularb-components/react@^3.3
```

```bash
pnpm add @suankularb-components/react@^3.3
```

### Highlights

#### Animation constants

**`useAnimationConfig()` is now deprecated.** Use the `DURATION` and `EASING`
constants instead.

```tsx
// OLD: `useAnimationConfig()`
import { transition, useAnimationConfig } from "@suankularb-components/react";
const { duration, easing } = useAnimationConfig();
transition(duration.short4, easing.standard);
```

```tsx
// NEW: `DURATION` and `EASING` constants
import { DURATION, EASING, transition } from "@suankularb-components/react";
transition(DURATION.short4, EASING.standard);
```

#### Tone-based surfaces

**Surface container roles replaced elevation-based surfaces.** Replace the
following CSS variables in your code.

- `surface-1` → `surface-container-low`
- `surface-2` → `surface-container`
- `surface-3` → `surface-container-high`
- `surface-4` → `surface-container-highest`
- `surface-5` → `surface-container-highest`

`surface-container-lowest`, `surface-dim`, `surface-bright` were also added.
See if these tokens can better replace your current usage of `surface-1` to
`surface-5`.
