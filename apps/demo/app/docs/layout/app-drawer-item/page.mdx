## App Drawer Item

Represents a single app inside the App Drawer. Always lives inside an
App Drawer Segment.

<LinksChipSet source="/AppDrawerItem.tsx" />

<DemoCard
  component={AppDrawerItem}
  initialProps={{
    name: "MyLearn+",
    logo: (
      <div className="from-surface-variant to-secondary-container size-16 bg-linear-to-b" />
    ),
  }}
/>

```tsx
<AppDrawerItem name="MyLearn+" logo={<img src="/my-learn.svg" />} />
```

### Props

- [`ActionableProps`](/docs/guides/shared-props): `command`, `commandFor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.
