## Side Sheet

A modal panel that slides in from the side of the screen for secondary
content — related information, settings, or navigation that doesn't need to
be front and center.

<LinksChipSet
  material="/components/side-sheets/overview"
  source="/SideSheet.tsx"
/>

```tsx
<SideSheet id="about-sheet">
  <Header>About Wasapol</Header>
  {/* ... */}
</SideSheet>
```

### Usage

A trigger button can open the Side Sheet via the Invoker Commands API.

```tsx
<Button command="show-modal" commandfor="about-sheet">
  Open side sheet
</Button>
```

### Props

- `StyleableProps` are available: `className` and `style`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      Content of the Side Sheet.

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="id" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The ID of the `<dialog>` element, for Invoker Commands API support.

      - Use with `command="show-modal"` and `commandfor={id}` on a trigger
        button to open the Side Sheet declaratively via the Invoker Commands
        API.
      - Use `command="request-close"` to close, not `command="close"`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="attach" required="never">
    <TableCell>`"left" | "right"`</TableCell>
    <TableCell>

      The edge of the screen the Side Sheet attaches to.

      - `"right"` attaches to the right edge in LTR, left in RTL. This is the
        default.
      - `"left"` attaches to the left edge in LTR, right in RTL.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
