## Side Sheet

A side sheet that slides in from the left.

```tsx
<SideSheet id="side-sheet">
  <NavDrawerSection header="Main">
    <NavDrawerItem icon={<MaterialIcon icon="home" />} selected>
      Home
    </NavDrawerItem>
  </NavDrawerSection>
</SideSheet>
```

### Usage

A trigger button can open the Side Sheet via the Invoker Commands API.

```tsx
<Button command="show-modal" commandfor="side-sheet">
  Open side sheet
</Button>
