## Section

Groups content under a single Header.

<LinksChipSet source="/Section.tsx" />

<DemoCard
  component={Section}
  initialProps={{
    children: [
      <Header key="h">Getting started</Header>,
      <p key="p" style={{ margin: 0 }}>
        SK Components (“SKCom”) is a design system consisting of tokens and
        components created with the goal of a consistent and harmonious
        experience across all Suankularb features and applications.
      </p>,
    ],
  }}
/>

```tsx
<Section>
  <Header>Getting started</Header>
  <p>
    SK Components (“SKCom”) is a design system consisting of tokens and
    components created with the goal of a consistent and harmonious experience
    across all Suankularb features and applications.
  </p>
</Section>
```

### Usage

**Put [Header](/docs/layout/header) as the first child of Section** to label
the Section for screen readers. This uses the `aria-labelledby` attribute under
the hood to automatically link the Section and Header together.

```tsx
<Section>
  <Header level={3}>About this feature</Header>
  {/* Section content */}
</Section>
```

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
