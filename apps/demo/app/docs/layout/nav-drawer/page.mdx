## Navigation Drawer

A navigation drawer that slides in from the left.

<LinksChipSet
  material="/components/navigation-drawer/overview"
  source="/NavDrawer.tsx"
/>

```tsx
<NavDrawer>
  <NavDrawerSection header="Search">
    <NavDrawerItem icon={<MaterialIcon icon="book" />} selected>
      Subjects
    </NavDrawerItem>
    <NavDrawerItem icon={<MaterialIcon icon="groups" />}>
      Classrooms
    </NavDrawerItem>
  </NavDrawerSection>
</NavDrawer>
```

> **Accessibility note:** When Navigation Drawer is open, screen readers may not
> announce client-side route changes because the `<dialog>` element makes live
> regions outside it inert. This is a known inconsistency across browsers and
> assistive technologies ([w3c/aria#1854](https://github.com/w3c/aria/issues/1854)).
