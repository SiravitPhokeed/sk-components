## Theme Provider

Sets up the CSS variables and default theme that all SK Components depend on.
Include this once near the root of your app tree.

<LinksChipSet material="/styles" source="/ThemeProvider.tsx" />

```tsx
import { ThemeProvider } from "@suankularb-components/react";

const App = () => (
  <>
    <ThemeProvider />
    <RootLayout>{/* ... */}</RootLayout>
  </>
);
```

### Props

Theme Provider has no props.
