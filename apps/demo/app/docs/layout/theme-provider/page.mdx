## Theme Provider

Provides default variables for SK Components.

```tsx
import { ThemeProvider } from "@suankularb-components/react";

const App = () => (
  <>
    <ThemeProvider />
    <RootLayout>{/* ... */}</RootLayout>
  </>
);
```

### Props

Theme Provider has no props.
