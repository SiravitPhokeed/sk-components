## Columns

Columns break up content in larger screens into multiple columns, so as to
make the content easier to read. On smaller screens, Columns automatically
collapse columns into one column.

The columns inside of Columns are based on the layout grid, which is a grid
system that keeps elements of a page aligned to a common grid
([M3 reference](https://m3.material.io/foundations/adaptive-design/large-screens/overview#55fc0118-1fa3-48a3-b805-169bb58e6e78);
[M2 reference](https://m2.material.io/design/layout/responsive-layout-grid.html#columns-gutters-and-margins)).

<DemoCard
  component={Columns}
  initialProps={{
    children: list(1, 12).map((i) => (
      <Card key={i} appearance="filled" className="grid place-items-center p-2">
        <Text type="title-medium">{i}</Text>
      </Card>
    )),
    columns: 3,
    className: "w-full min-h-72 items-stretch",
  }}
  adjustableProps={{
    columns: [2, 3, 4, 6, 12],
  }}
/>

```tsx
<Columns columns={3}>
  <div>Column 1</div>
  <div>Column 2</div>
  <div>Column 3</div>
</Columns>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
