## Nav Drawer Item

A destination in a Navigation Drawer. Should be a child of a Navigation
Drawer Section.

<LinksChipSet
  material="/components/navigation-drawer/overview"
  source="/NavDrawerItem.tsx"
/>

<DemoCard
  component={NavDrawerItem}
  initialProps={{
    icon: <MaterialIcon icon="book" />,
    label: "Subjects",
    className: "w-84", // Actual width if inside Nav Drawer
  }}
  adjustableProps={{
    selected: "boolean",
  }}
/>

```tsx
<NavDrawerItem icon={<MaterialIcon icon="book" />} label="Subjects" selected />
```

### Props

- [`ActionableProps`](/docs/guides/shared-props): `command`, `commandFor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.
