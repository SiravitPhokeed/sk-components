## Root Layout

The container for everything in your application. Components like [Navigation
Drawer](/docs/layout/nav-drawer), [Navigation Bar](/docs/layout/nav-bar),
[FAB](/docs/inputs/fab), and [Page Header](/docs/layout/page-header) each
appear exactly once, and they work best as direct children of Root Layout.

Root Layout handles component positioning and responsiveness.

<LinksChipSet source="/RootLayout.tsx" />

```tsx
<RootLayout element="body">
  <NavBar>{/* Navigation Bar Items */}</NavBar>
  <NavDrawer>{/* Navigation Drawer Sections */}</NavDrawer>
  <FAB {/* FAB props */} />
  <PageHeader>Dashboard</PageHeader>
  <ContentLayout>{/* Sections */}</ContentLayout>
</RootLayout>
```

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      Root Layout manages the placement of Navigation Drawer, Navigation Bar,
      and FAB.

      - These six components should be direct children of Root Layout:
        - Navigation Drawer
        - Navigation Bar
        - FAB
        - Page Header
        - [Content Layout](/docs/layout/content-layout)
        - [Split Layout](/docs/layout/split-layout)
      - All other elements should go inside Content Layout or Split Layout.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the Skip Link accessibility label.

      - Must be `en-US` or `th`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="skipToContent" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Whether to render a Skip Link as the first child. The Skip Link allows
      keyboard users to jump directly to the main content.

      - Optional. Defaults to `true`.

      </TableCell>

  </PropsTableRow>
</PropsTable>
