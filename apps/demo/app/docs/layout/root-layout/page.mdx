## Root Layout

The container of everything inside an application. Components which must
appear only once — Navigation Drawer, Navigation Bar, FAB, and Page Header —
only work optimally as direct descendants of Root Layout.

Root Layout handles positioning of components and responsiveness.

<LinksChipSet source="/RootLayout.tsx" />

```tsx
<RootLayout element="body">
  <NavBar>{/* Nav Bar Items */}</NavBar>
  <NavDrawer>{/* Nav Drawer Sections */}</NavDrawer>
  <FAB {/* FAB props */} />
  <PageHeader>Dashboard</PageHeader>
  <ContentLayout>{/* Sections */}</ContentLayout>
</RootLayout>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
