## Tab

Tabs allow the user to switch between pages on the same level of a page
hierarchy. For example, an Overview, Students, and Teachers page of a class.

<LinksChipSet material="/components/tabs/overview" source="/Tab.tsx" />

```tsx
<Tab icon={<MaterialIcon icon="info" />} label="Info" selected />
```

### Props

- [`ActionableProps`](/docs/guides/shared-props): `command`, `commandFor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

<PropsTable>
  <PropsTableRow prop="icon" required="conditional">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon appears before or above the label. Icons help users identify pages
      more quickly.

      - If the icon is sufficiently representative of the page, a label isn’t
        needed.
      - Normally optional, but required if `label` is not defined, as a Tab cannot
        be empty.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="label" required="conditional">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      An additional text label next to or underneath the icon.

      - Required if `icon` is not defined, as a Tab cannot be empty.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="alt" required="conditional">
    <TableCell>`string`</TableCell>
    <TableCell>

      A description of the Tab for screen readers, similar to `alt` on `<img>`.

      - Required if the Tab just includes `icon`, because an icon has no
        significance for screen readers.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="tooltip" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A message shown in a tooltip when the user hovers over the Tab.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="selected" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Highlights the Tab. If the user is currently on this page, the Tab should
      be highlighted.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
