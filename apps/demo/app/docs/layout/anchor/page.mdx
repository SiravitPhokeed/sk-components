## Anchor

Associates elements for CSS Anchor Positioning via the `anchor-name`
CSS property, and passes the generated name through React context so
child popover components (e.g. Menu) can auto-resolve their
`position-anchor`.

### Usage

The **implicit pattern** is the recommended way to use Anchor.

- Put the trigger element (e.g. a Button) and the positioned element (e.g. a Menu)
  inside an Anchor.

```tsx
<Anchor>
  <Button appearance="filled" command="show-popover" commandfor="share-menu">
    Share
  </Button>
  <Menu id="share-menu">
    <MenuItem icon={<MaterialIcon icon="email" />}>Email</MenuItem>
    <MenuItem icon={<MaterialIcon icon="chat" />}>Messages</MenuItem>
  </Menu>
</Anchor>
```

The **explicit pattern** is useful when the trigger and positioned elements are
not adjacent in the DOM.

- Wrap the trigger element in an Anchor and give it a `name` prop
  (dashed-ident).
- Give the positioned element an `anchor` prop with the same value as the Anchor’s
  `name` prop.

```tsx
<Anchor name="--share-menu-anchor">
  <Button appearance="filled" command="show-popover" commandfor="share-menu">
    Share
  </Button>
</Anchor>
<Menu id="share-menu" anchor="--share-menu-anchor">
  <MenuItem icon={<MaterialIcon icon="email" />}>Email</MenuItem>
  <MenuItem icon={<MaterialIcon icon="chat" />}>Messages</MenuItem>
</Menu>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.

  <PropsTableRow prop="children" required="always">

      - Always required.

      </TableCell>

  <PropsTableRow prop="name" required="never">
    <TableCell>`--{string}`</TableCell>
    <TableCell>

      The anchor name (dashed-ident) used for CSS Anchor Positioning.

      - Optional. Auto-generated if omitted.
      - When using the flexible pattern (Anchor wraps trigger only, Menu
        positioned elsewhere), set this explicitly and pass the same value
        to the Menu’s `anchor` prop.
      - Must be a valid dashed-ident (e.g. `--menu-trigger`).

      </TableCell>
