## Tabs Container

A group of Tabs. Tabs allow the user to switch between pages on the same
level of a page hierarchy. For example, an Overview, Students, and Teachers
page of a class.

<DemoCard
  component={TabsContainer}
  initialProps={{

  }}
  adjustableProps={{
    appearance: ["primary", "secondary"],
  }}

```tsx
<TabsContainer appearance="primary">
  <Tab icon={<MaterialIcon icon="overview" />} label="Overview" selected />
  <Tab icon={<MaterialIcon icon="group" />} label="Students" />
  <Tab icon={<MaterialIcon icon="school" />} label="Teachers" />
</TabsContainer>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
