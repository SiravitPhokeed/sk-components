## Header

A Header helps users quickly identify sections and their purpose.

When used in conjunction with Section, the Section can be labeled with the
Header for screen readers.

<LinksChipSet source="/Header.tsx" />

<DemoCard
  component={Header}
  initialProps={{
    children: "Getting started",
  }}
  adjustableProps={{
    level: [2, 3, 4, 5, 6],
  }}
/>

```tsx
<Header level={2}>Getting started</Header>
```

### Usage

**Use “Sentence case”** instead of “Title Case” for the text in Header.

<figure className="mt-3 mb-6 space-y-2">
  <Header
    children="About this feature"
    icon={<MaterialIcon icon="check_circle" className="text-primary" />}
    level={4}
  />
  <Header
    children="About This Feature"
    icon={<MaterialIcon icon="cancel" className="text-error" />}
    level={4}
  />
</figure>

**Put Header as the first child of [Section](/docs/layout/section)** to label
the Section for screen readers. This uses the `aria-labelledby` attribute under
the hood to automatically link the Section and Header together.

```tsx
<Section>
  <Header level={3}>About this feature</Header>
  {/* Section content */}
</Section>
```

**Don’t skip heading levels**. The Header level should be one level lower than the
previous Header. The default Header level is `2`, which corresponds to `<h2>`.

```tsx
<Header>Getting started</Header>
<Header level={3}>Installation</Header>
<Header level={4}>Using npm</Header>
<Header level={4}>Using pnpm</Header>
```

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The text or heading content of the Header. This is typically a short
      string that identifies a section or page.

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="level" required="never">
    <TableCell>`2 | 3 | 4 | 5 | 6`</TableCell>
    <TableCell>

      The level of the Header. The number corresponds to an HTML header element,
      i.e., `3` corresponds to `<h3>`.

      - `2` by default.
      - Must be a number from 2-6. `1` is not allowed as `<h1>` is reserved for Page Header.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="icon" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon can appear before the text (`children`) in a Header. In a page
      with many headers, icons can quickly orient users.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as the value for `icon`.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
