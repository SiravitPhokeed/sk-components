## Content Layout

A centered, single-column container for page content. It limits the
maximum width and arranges children vertically, with minimal built-in
styling.

<LinksChipSet source="/ContentLayout.tsx" />

```tsx
<ContentLayout>
  <Section>
    <Header>Getting started</Header>
    {/* ... */}
  </Section>
</ContentLayout>
```
