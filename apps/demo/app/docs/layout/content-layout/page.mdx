## Content Layout

A simple width-clamped vertical flow of content with minimal default styling.

```tsx
<ContentLayout>
  <Section>
    <Header>Getting started</Header>
    {/* ... */}
  </Section>
</ContentLayout>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
