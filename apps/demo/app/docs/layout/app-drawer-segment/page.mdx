## App Drawer Segment

A group of apps in the App Drawer.

<DemoCard
  component={AppDrawerSegment}
  initialProps={{
    title: "School apps",
    children: [
      <AppDrawerItem key="1" name="Main site" logo={<div className="size-16 bg-linear-to-b from-surface-variant to-primary-container" />} />,
      <AppDrawerItem key="2" name="MyLearn+" logo={<div className="size-16 bg-linear-to-b from-surface-variant to-secondary-container" />} />,
    ],
    className: "w-77", // Actual width if inside App Drawer
  }}
/>

```tsx
<AppDrawerSegment title="School apps">
  <AppDrawerItem name="Main site" logo={<img src="/main.svg" />} />
  <AppDrawerItem name="MyLearn+" logo={<img src="/my-learn.svg" />} />
</AppDrawerSegment>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
