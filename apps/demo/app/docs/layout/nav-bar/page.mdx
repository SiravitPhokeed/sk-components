## Navigation Bar

A Navigation Bar provides persistent access to all top-level pages. On larger screens,
it transforms into a Navigation Rail.

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="alt" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A description of the Navigation Bar for screen readers, similar to `alt`
      on `<img>`. Applied as `aria-label` on the `<nav>` element.

      - Optional. Defaults to a localized &ldquo;Main&rdquo; string.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      A Navigation Bar contains Navigation Bar Items, each leading to a
      different top-level page. These pages should only be navigated to from
      the Navigation Bar and the Navigation Drawer.

      - Must include at least 3 Navigation Bar Items.
      - Must not include more than 5 Navigation Bar Items visible on mobile.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="end" required="never">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      More Navigation Items can be placed on the bottom of the Navigation Rail
      on larger screens. Use cases are settings and log out.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the accessibility labels.

      - Must be `en-US` or `th`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onNavToggle" required="never">
    <TableCell>`() => any`</TableCell>
    <TableCell>

      The function called when the user clicks on the navigation Button.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
