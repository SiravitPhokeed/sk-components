## Getting started

**SK Components (“SKCom”) is a design system based on
[Material Design 3](https://m3.material.io/)** consisting of tokens and
components created with the goal of a **consistent and harmonious experience
across all Suankularb features** and applications.

There are currently 2 official SKCom libraries:

- **SK Components Styles** (`@suankularb-components/styles`) — a CSS library
  that other libraries can use to implement the design system.
- **React SK Components** (`@suankularb-components/react`, **“ReSKCom”**) — a
  React library that provides React components that implement the design system.

This documentation is for **ReSKCom**, which is the recommended library for
React applications.

> SK Components v4 is now available. If you are using v3, [learn how to upgrade
> here](/docs/migrations/v4).

> Since SKCom is based on Material Design 3, visit the [Material Design 3
> documentation](https://m3.material.io/) for more information on the design
> system, including its principles, components, and tokens.
>
> Also, refer to the [style guide](https://m3.material.io/foundations/content-design/style-guide/ux-writing-best-practices)
> when writing content for your application.

<DisclosureCard summary="Is M3 Expressive supported?">

No, SKCom is based on Material Design 3 Baseline, so
[M3 Expressive](https://m3.material.io/blog/building-with-m3-expressive)
features like updated components and the motion physics system aren’t
available.

This is to reduce compatibility issues for those
[upgrading from v3 to v4](/docs/migrations/v4), so there is currently no plan
to implement M3 Expressive in SKCom.

</DisclosureCard>

### Installation

```bash
npm install @suankularb-components/react
```

```bash
pnpm add @suankularb-components/react
```

`react` and `react-dom` are peer dependencies, so you need to install them as
well if you haven’t already. React 18 and up are supported.

#### Fonts

**Fonts are not bundled with the library,** so you need to install them
yourself. These fonts are used by the default theme included with [Theme
Provider](/docs/layout/theme-provider):

- [Inter](https://fonts.google.com/specimen/Inter)
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)
- [Sarabun](https://fonts.google.com/specimen/Sarabun)
- [IBM Plex Sans Thai](https://fonts.google.com/specimen/IBM+Plex+Sans+Thai)

[Material Icon](/docs/data/material-icon) uses the Material Symbols Outlined
font. See the [Material Symbols documentation](https://fonts.google.com/icons)
for a list of icons and installation instructions.

### Usage

- Import components from `@suankularb-components/react` and use them in your
  React application.
  - For imperative helpers like [`snackbar.push()`](/docs/overlays/snackbar),
    import them from `@suankularb-components/react/helpers`.
- To use the default theme, simply add `<ThemeProvider />` to your app.
- Root Layout must enclose all pages, as it provides the default layout and
  global styles.
  - Layout components like [Page Header](/docs/layout/page-header) and [Content
    Layout](/docs/layout/content-layout) must be direct children of Root Layout.
  - See [Root Layout](/docs/layout/root-layout) for more information.

```tsx
import {
  Button,
  ContentLayout,
  PageHeader,
  RootLayout,
  Text,
  ThemeProvider,
} from "@suankularb-components/react";
import { snackbar } from "@suankularb-components/react/helpers";

const App = () => (
  <>
    <ThemeProvider />
    <RootLayout>
      <PageHeader>Hello world!</PageHeader>
      <ContentLayout>
        <Text type="body-large">Welcome to SK Components.</Text>
        <Button
          appearance="filled"
          onClick={() => snackbar.push("Hello, world!")}
        >
          Click me!
        </Button>
      </ContentLayout>
    </RootLayout>
  </>
);
```
