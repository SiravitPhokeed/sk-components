## Getting started

<div className="grid grid-cols-3 md:grid-cols-4 *:[p]:col-span-3 *:my-2 *:[img]:min-w-20 *:[img]:rounded-lg gap-x-4">

<Image src={MaterialGraphic} alt="" priority />
**SK Components (“SKCom”) is a component library built on [Material Design
3](https://m3.material.io/).** It provides components that follow Material
Design principles, so you can ship faster with components that already handle
styling, accessibility, and behavior.

<Image src={SuankularbGraphic} alt="Long Building, Suankularb Wittayalai School" priority />
**SKCom was originally created for [Suankularb Wittayalai
School](https://www.sk.ac.th/)**’s family of applications, including its
flagship application [MySK](https://mysk.school/), and continues to serve
Suankularb students and staff today.

<Image src={UpgradeGraphic} alt="" priority />

**Already using v3? [Learn how to upgrade to v4](/docs/migrations/v4).** Say
goodbye to manual state management and hello to declarative modals, improved
accessibility, Next.js App Router support, and more.

</div>

> **Before you build:** Material Design 3 has an excellent
> [style guide](https://m3.material.io/foundations/content-design/style-guide/ux-writing-best-practices)
> and detailed
> [component documentation](https://m3.material.io/components). Misusing
> components — like putting the wrong kind of action on a Button or using a
> Dialog when a separate page would be better — creates confusing experiences.
>
> Most SKCom component pages link to the relevant Material Design page at the
> top, so you can **check the official guidance before you start.**

There are currently two official SKCom libraries:

- **SK Components Styles** (`@suankularb-components/css`) — a CSS library
  that other libraries can use to implement the design system.
- **React SK Components** (`@suankularb-components/react`, **“ReSKCom”**) — a
  React library that provides React components implementing the design system.

This documentation is for **ReSKCom**, which is the recommended library for
React applications.

### Installation

```bash
npm install @suankularb-components/react
```

```bash
pnpm add @suankularb-components/react
```

`react` and `react-dom` are peer dependencies — your project must provide
them rather than the library bundling its own copy. React 18 and later are
supported. If you’re starting from scratch, install them first.

#### Fonts

**Fonts are not bundled with the library,** so you need to install them
yourself. These fonts are used by the default theme included with
[Theme Provider](/docs/layout/theme-provider):

- [Inter](https://fonts.google.com/specimen/Inter)
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)
- [Sarabun](https://fonts.google.com/specimen/Sarabun)
- [IBM Plex Sans Thai](https://fonts.google.com/specimen/IBM+Plex+Sans+Thai)

[Material Icon](/docs/data/material-icon) uses the Material Symbols Outlined
font. See the [Material Symbols documentation](https://fonts.google.com/icons)
for a list of icons and installation instructions.

### Usage

**Import components** from `@suankularb-components/react` and use them in
your React application. For imperative helpers like
[`snackbar.push()`](/docs/overlays/snackbar), import them from
`@suankularb-components/react/helpers`.

**Add the default [theme](/docs/layout/theme-provider)** by placing
`<ThemeProvider />` in your app. It provides the CSS variables all components
depend on.

**Wrap your app** with `<RootLayout>`. It provides the default page layout
and global styles. Layout components like
[Page Header](/docs/layout/page-header) and
[Content Layout](/docs/layout/content-layout) must be direct children of
[Root Layout](/docs/layout/root-layout).

```tsx
import {
  Button,
  ContentLayout,
  PageHeader,
  RootLayout,
  Text,
  ThemeProvider,
} from "@suankularb-components/react";
import { snackbar } from "@suankularb-components/react/helpers";

const App = () => (
  <>
    <ThemeProvider />
    <RootLayout>
      <PageHeader>Hello world!</PageHeader>
      <ContentLayout>
        <Text type="body-large">Welcome to SK Components.</Text>
        <Button
          appearance="filled"
          onClick={() => snackbar.push("Hello, world!")}
        >
          Click me!
        </Button>
      </ContentLayout>
    </RootLayout>
  </>
);
```

<DisclosureCard summary="Is M3 Expressive supported?">

No, SKCom is based on Material Design 3 Baseline, so
[M3 Expressive](https://m3.material.io/blog/building-with-m3-expressive)
features like updated components and the motion physics system aren’t
available.

This is to reduce compatibility issues for those
[upgrading from v3 to v4](/docs/migrations/v4), so there is currently no
plan to implement M3 Expressive in SKCom.

</DisclosureCard>
