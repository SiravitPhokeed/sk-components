## Shared props

Many SKCom components inherit props from a few shared types. Rather than
documenting these props on every component page, they are listed here.

### `StyleableProps`

Every component accepts `className` and `style`, so you can customize its
appearance like any other HTML element.

```tsx
<Button appearance="filled" style={{ backgroundColor: "rebeccapurple" }}>
  Purple button
</Button>
```

### `ElementCustomizableProps`

Many components let you swap their underlying HTML tag. This is useful when
you need a different semantic element, or when integrating with framework
link components like Next.js’s
[`Link` component](https://nextjs.org/docs/app/api-reference/components/link).

```tsx
import Link from "next/link";

<Button appearance="filled" href="/dashboard" element={Link}>
  Go to dashboard
</Button>;
```

If you don’t provide an `element`, the component uses a sensible default
(usually a `<button>`, `<a>`, or `<div>`). Check each component’s page for
its specific default.

### `ActionableProps`

Interactive components like Button, List Item, and Navigation Bar Item can
receive interaction props. These include standard event handlers as well as
[Invoker Commands API](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API)
props for declarative modals and popovers.

```tsx
<Button command="show-modal" commandfor="settings-dialog">
  Open settings
</Button>
```

Learn more in the [modals and popovers](/docs/guides/modals) guide.
