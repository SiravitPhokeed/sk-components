## Using with Next.js App Router

Integrate SKCom into your [Next.js](https://nextjs.org/) project using the
[App Router](https://nextjs.org/docs/app).

<RouterSelector value="app" />

### Setup

In your Next.js project, install the package.

```bash
npm install @suankularb-components/react
```

```bash
pnpm add @suankularb-components/react
```

Create a `layout.tsx` file in the `app` directory if you don’t have one already.
Then, add [Theme Provider](/docs/layout/theme-provider) and wrap your app with
[Root Layout](/docs/layout/root-layout) in the file.

```tsx
// app/layout.tsx

import {
  RootLayout as SKCRootLayout,
  ThemeProvider,
} from "@suankularb-components/react";
import type { ReactNode } from "react";

const RootLayout = ({ children }: { children: ReactNode }) => (
  <html lang="en">
    <ThemeProvider />
    <SKCRootLayout>{children}</SKCRootLayout>
  </html>
);

export default RootLayout;
```

### Layout

You can create `@/components/NavBar.tsx` and `@/components/NavDrawer.tsx` using
SKCom’s Nav Bar and Nav Drawer components and populate them with your app’s
navigation items.

```tsx
// components/NavBar.tsx

import { NavBar as SKCNavBar } from "@suankularb-components/react";
import Link from "next/link";
import { usePathname } from "next/navigation";

const NavBar = () => {
  const pathname = usePathname();

  return (
    <SKCNavBar>
      <NavBarItem
        icon={<MaterialIcon icon="home" />}
        label="Home"
        href="/"
        selected={pathname === "/"}
        element={Link}
      />
      {/* ... */}
    </SKCNavBar>
  );
};
```

`@/components/NavDrawer.tsx` can be created in a similar way. Then, import these
components into your `layout.tsx` file.

```tsx
// app/layout.tsx

import NavBar from "@/components/NavBar";
import NavDrawer from "@/components/NavDrawer";
import {
  RootLayout as SKCRootLayout,
  ThemeProvider,
} from "@suankularb-components/react";
import type { ReactNode } from "react";

const RootLayout = ({ children }: { children: ReactNode }) => (
  <html lang="en">
    <ThemeProvider />
    <SKCRootLayout>
      <NavBar />
      <NavDrawer />
      {children}
    </SKCRootLayout>
  </html>
);

export default RootLayout;
```

### Fonts

You can use
[`next/font`](https://nextjs.org/docs/app/api-reference/components/font) to
load the fonts used in SKCom.

#### Google Fonts

Inter, Space Grotesk, Sarabun, and IBM Plex Sans Thai are available on Google
Fonts. You can load them using `next/font/google` in your root layout file (e.g., `app/layout.tsx`).

```ts
import {
  Fira_Code,
  IBM_Plex_Sans_Thai,
  Inter,
  Sarabun,
  Space_Grotesk,
} from "next/font/google";

const bodyFontEN = Inter({ subsets: ["latin"] });
const displayFontEN = Space_Grotesk({ subsets: ["latin"] });
const bodyFontTH = IBM_Plex_Sans_Thai({
  weights: ["300", "400", "500", "700"],
  subsets: ["thai"],
});
const displayFontTH = Sarabun({
  weights: ["300", "400", "500", "700"],
  subsets: ["thai"],
});
```

Then, add the font class names to your Root Layout component.

```tsx
<SKCRootLayout
  className={[
    bodyFontEN.className,
    displayFontEN.className,
    bodyFontTH.className,
    displayFontTH.className,
  ].join(" ")}
>
  {/* ... */}
</SKCRootLayout>
```

**Save the downloaded font file as `material-symbols.woff2` in your project’s
`public/fonts` directory.** Then, load the font using `next/font/local` in your
`layout.tsx` file.

Take care to match the relative path to the font file with your project
structure.

```tsx
import localFont from "next/font/local";

const iconFont = localFont({
  src: "../public/fonts/material-symbols.woff2",
  weight: "100 700",
  style: "normal",
  variable: "--font-icon",
  display: "block",
});
```

Finally, add the font class name to your Root Layout component.

```tsx
<SKCRootLayout
  className={[
    // Google Fonts
    bodyFontEN.className,
    displayFontEN.className,
    bodyFontTH.className,
    displayFontTH.className,
    // Icon font
    iconFont.variable,
  ].join(" ")}
>
  {/* ... */}
</SKCRootLayout>
```

### Navigation

**Many interactive components** have props that extend `ElementCustomizableProps`
and thus **accept an `element` prop.** This allows you to use Next.js’s
[`Link` component](https://nextjs.org/docs/pages/api-reference/components/link)
for navigation instead of the default `<a>` element.

```tsx
<Button href="/about" element={Link}>
  About
</Button>
```
