## Browser support

SK Components supports modern evergreen browsers. Internet Explorer is not
supported.

### Full support

**All features work as documented.**

### Partial support

**CSS Anchor Positioning and Invoker Commands are unavailable in these browsers.**

  <BrowsersGridItem browser="chrome" version="114+" releaseDate="2023-05-30" />
  <BrowsersGridItem browser="firefox" version="125+" releaseDate="2024-04-16" />
  <BrowsersGridItem browser="safari" version="17+" releaseDate="2023-09-18" />

</BrowsersGrid>

If you must support these older browsers, note the following:

- [Anchor](/docs/overlays/anchor) is _not supported_ in these browsers. All
  modals and popovers appear in the center of the viewport, and cannot be
  anchored to a trigger element.
- `command` and `commandfor` props are _not supported_ in these browsers. **You
  must use controlled modals and popovers** with the `open` and `onClose` props.
- Learn more about [controlled modals and popovers](/docs/guides/modals#controlled-mode).

> **No polyfills required.** The CSS package is pre-compiled with Lightning CSS,
> which handles `light-dark()` and CSS nesting at build time. You do not need to
> add polyfills or configure your bundler for SK Components.
