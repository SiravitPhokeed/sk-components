## Browser support

SK Components is tested against the browsers listed below. Pick the tier that
matches the browser versions you need to support. No polyfills or bundler
configuration is required.

If you must support these older browsers, here is what to expect:

- **[Menu](/docs/overlays/menu), [Select](/docs/inputs/select), and
  [Filter Chip](/docs/inputs/filter-chip) menus** appear as bottom sheets
  centered at the bottom of the viewport, rather than floating next to their
  trigger.
- **[Table Row](/docs/data/table-row) actions** appear as an always-visible
  inline column instead of a hover-revealed toolbar above the row.
- **Custom commands** (`command="--*"`) only work on browsers with native
  [Invoker Commands](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API)
  support. The six built-in commands work on all supported browsers.

Everything else, including uncontrolled modals and popovers, works the same
across all supported browsers. See the [modals and popovers guide](/docs/guides/modals)
for more details.

<DisclosureCard summary="Why are there different support tiers?">

SK Components uses **three modern web platform features** to power popovers and
modals.

- [CSS Anchor Positioning](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_anchor_positioning)
  tethers popovers and menus to their trigger elements. This is only available
  on the <SupportTierIcon tier="full" inline /> full support tier. On
  the <SupportTierIcon tier="partial" inline /> **partial support tier, popovers
  appear as bottom sheets** instead.
- The [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API)
  places popover content in the top layer above all other page content.
  **Popovers do not appear on browsers with <SupportTierIcon tier="none" inline />
  no support,** where this API is unavailable.
- The [Invoker Commands API](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API)
  lets buttons open and close popovers and modals declaratively. On
  the <SupportTierIcon tier="partial" inline /> **partial support tier,** where
  this API is unavailable, **SK Components provides a JavaScript fallback** so
  `command` and `commandfor` still work. Only custom commands require the native
  API.

The <SupportTierIcon tier="full" inline />
full support tier requires all three features. The <SupportTierIcon tier="partial" inline />
partial support tier requires only the Popover API.
