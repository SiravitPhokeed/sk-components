## Data Table Body

The body section of a Data Table, designed to work with TanStack Table.
For the non-TanStack path, use Table Body instead.

<LinksChipSet source="/DataTableBody.tsx" />

```tsx
<DataTableBody rowModel={table.getRowModel()} />
```

### Props

- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

<PropsTable>
  <PropsTableRow prop="rowModel" required="always">
    <TableCell>`RowModel<RowShape>`</TableCell>
    <TableCell>

      The return of `getRowModel`, one of the functions of the TanStack Table
      instance.

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="align" required="never">
    <TableCell>`"left" | "center" | "right"`</TableCell>
    <TableCell>

      How the content in each cell should be positioned. It can be aligned to the
      left (default), the center, or the right.

      - Must be `left`, `center`, `right`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="rowActions" required="never">
    <TableCell>`ReactElement | (row: RowShape) => ReactElement`</TableCell>
    <TableCell>

      Actions related to a row, shown on hover.

      - Must be a Segmented Button.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
