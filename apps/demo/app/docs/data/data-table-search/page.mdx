## Data Table Search

Allows the user to filter the Data Table’s content using a text query.

<DemoCard
  component={DataTableSearch}
  initialProps={{
    placeholder: "Search tasks",
    className: "w-full min-w-80",
  }}
/>

```tsx
<DataTableSearch
  value={search}
  onChange={setSearch}
  placeholder="Search tasks"
/>
```

### Usage

**Data Table Search does not manage the data of the table.** You can use the
`value` and `onChange` props to control the field’s value and trigger the
filtering logic when the user makes changes to the field.

**With Tanstack Table**, you can hook up the `onChange` function to
`setGlobalFilter` to filter the table’s content.

```tsx
const [globalFilter, setGlobalFilter] = useState("");

const table = useReactTable({
  // ...
  state: { globalFilter },
  onGlobalFilterChange: setGlobalFilter,
  getCoreRowModel: getCoreRowModel(),
  getFilteredRowModel: getFilteredRowModel(),
});

return (
  <DataTable>
    <DataTableSearch value={globalFilter} onChange={setGlobalFilter} />
    <DataTableContent>
      <DataTableHead headerGroups={getHeaderGroups()} />
      <DataTableBody rowModel={getRowModel()} />
    </DataTableContent>
  </DataTable>
);
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.

<PropsTable>
  <PropsTableRow prop="value" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      The value inside the search field. This is useful if you want a
      controlled input.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the default placeholder message.

      - Must be `"en-US"` or `"th"`, as SKCom currently only support those 2
        languages.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onChange" required="never">
    <TableCell>`(value: string) => any`</TableCell>
    <TableCell>

      This function triggers when the user make changes to the field value. The
      value is passed in via the function.

      - With [Tanstack Table](https://tanstack.com/table/), this function
        can be hooked up to `setGlobalFilter`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="placeholder" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A faint text displayed inside the field guiding the user.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="inputAttr" required="never">
    <TableCell>`ComponentProps<"input">`</TableCell>
    <TableCell>

      Attributes for the underlying `<input>` element used as the field.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
