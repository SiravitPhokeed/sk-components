## Header

A Header helps users quickly identifies sections and their purpose.

When used in conjunction with Section, the Section can be labeled with the
Header for screen readers.

<DemoCard

    level: [2, 3, 4, 5, 6],

```tsx
<Header level={2}>Getting started</Header>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
