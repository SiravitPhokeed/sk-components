## Input Chip

A Chip displaying a piece of information entered by the user is an Input
Chip. This type of Chip can be added and deleted by the user.

Like all Chips, an Input Chip appears alongside other Input Chips.
They can also appear inside a text field like Chip Field.

### Props

- [`ActionableProps`](/docs/guides/shared-props): `command`, `commandFor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The text displayed inside the chip.

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="avatar" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An avatar is placed before all content in an Input Chip. A use case would
      be the profile picture of a user.

      - You are encouraged to use [Avatar](/docs/data/avatar) as the value for `avatar`.
      - Incompatible with `icon`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="icon" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon can appear before the text in an Input Chip. In a page with many
      chips, icons can quickly orient users.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as the value for `icon`.
      - Incompatible with `avatar`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="tooltip" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A message shown in a tooltip when the user hovers over the Input Chip.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="selected" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      If the Input Chip is selected. `avatar` or `icon` is replaced with a
      checkmark if this is `true`.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the accessibility labels.

      - Must be `th` or `en-US`, SKCom supports two languages: th and en-US.
        languages.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onDelete" required="never">
    <TableCell>`() => any`</TableCell>
    <TableCell>

      Triggers when the user clicks the delete button.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
