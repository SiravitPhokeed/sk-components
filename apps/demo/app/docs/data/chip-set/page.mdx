## Chip Set

Chips normally appear alongside each other. A Chip Set is a container for
Chips, handling gaps, wrap, etc.

<LinksChipSet source="/ChipSet.tsx" />

<DemoCard

  initialProps={{

      <>

        <FilterChip>Blue</FilterChip>
        <FilterChip>Yellow</FilterChip>
      </>
    ),
  }}
/>

```tsx
<ChipSet>
  <FilterChip selected>Blue</FilterChip>
  <FilterChip>Yellow</FilterChip>
  <FilterChip>Green</FilterChip>
</ChipSet>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.
