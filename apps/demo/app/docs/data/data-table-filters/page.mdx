## Data Table Filters

Allows the user to filter the Data Table’s content by selecting from a list
of filters.

<DemoCard
  component={DataTableFilters}
  initialProps={{
    children: (
      <ChipSet>
        <FilterChip selected>Active</FilterChip>
        <FilterChip>Inactive</FilterChip>
      </ChipSet>
    ),
    className: "w-full min-w-80",
  }}
/>

```tsx
<DataTableFilters>
  <ChipSet>
    <FilterChip selected>Active</FilterChip>
    <FilterChip>Inactive</FilterChip>
  </ChipSet>
</DataTableFilters>
```

### Usage

**Data Table Filters does not manage the data of the table.** You can use the
`children` prop to pass in a Chip Set of Filter Chips and trigger the filtering
logic when the user selects a filter.

**With Tanstack Table**, you can hook up the Filter Chips to `columnFilters` to
filter the table’s content.

```tsx
const [filter, setFilter] = useState("all");
const table = useReactTable({
  // ...
  state: { columnFilters: [{ id: "status", value: filter }] },
  onColumnFiltersChange: setColumnFilters,
  getCoreRowModel: getCoreRowModel(),
  getFilteredRowModel: getFilteredRowModel(),
});

return (
  <DataTable>
    <DataTableFilters>
      <ChipSet>
        <FilterChip
          selected={filter === "active"}
          onClick={() => setFilter("active")}
        >
          Active
        </FilterChip>
        <FilterChip
          selected={filter === "inactive"}
          onClick={() => setFilter("inactive")}
        >
          Inactive
        </FilterChip>
      </ChipSet>
    </DataTableFilters>
    <DataTableContent>
      <DataTableHead headerGroups={getHeaderGroups()} />
      <DataTableBody rowModel={getRowModel()} />
    </DataTableContent>
  </DataTable>
);
```
