```tsx
<TableHead fixed>
  <TableRow>
    <TableCell header>Test date</TableCell>
    <TableCell header>Method</TableCell>
    <TableCell header>Result</TableCell>
  </TableRow>
</TableHead>
```

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      Table Head has the same behavior as `<thead>`.

      - Must consist of Table Row(s), which must consist of Table Cells with the
        `header` enabled.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="fixed" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      If the Table Head stays put on scroll.

      - Table Head will be fixed to the top of the parent Table, not the screen.
      - Only effective if `height` is set on the parent Table.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
