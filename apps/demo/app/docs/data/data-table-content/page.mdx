## Data Table Content

The main part of a Data Table.

<LinksChipSet source="/DataTableContent.tsx" />

```tsx
<DataTableContent contentWidth={800}>
  <DataTableHead headerGroups={table.getHeaderGroups()} />
  <DataTableBody rowModel={table.getRowModel()} />
</DataTableContent>
```

### Props

- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      A Data Table Content’s content depends on whether you decide to use
      TanStack Table or not.

      - If you opt in to TanStack Table: must include both Data Table Head and
        Data Table Body.
      - If you opt to use your own table solution: must include both Table Head
        and Table Body.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="contentWidth" required="never">
    <TableCell>`number`</TableCell>
    <TableCell>

      The minimum width of the content. When the table’s width is lower than
      this value, it becomes scrollable. Otherwise, the content fills the width
      of the Data Table.

      - Optional.

      </TableCell>

  </PropsTableRow>
  <PropsTableRow prop="alt" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A description of the Data Table for screen readers, similar to `alt`
      on `<img>`. Applied as `aria-label` on the `<table>`.

      - Optional.

      </TableCell>

  </PropsTableRow>

</PropsTable>
