The foot area of a Table.

```tsx
<TableFoot>
  <TableRow>
    <TableCell header colSpan={2}>
      Total
    </TableCell>
    <TableCell>THB 200.00</TableCell>

</TableFoot>
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      Table Foot has the same behaviour as `<tfoot>`.

      - Must consist of Table Rows, which must consist of Table Cells.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="fixed" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      If the Table Foot stays put on scroll.

      - Table Foot will be fixed to the bottom of the parent Table, not the
        screen.
      - Only effective if `height` is set on the parent Table.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
