## Data Table Pagination

At the footer of a Data Table, Data Table Pagination provides controls for
paginating the Data Table data, including the current rows and navigating
forward and backward on pages.

<DemoCard
  component={DataTablePagination}
  initialProps={{
    rowsPerPage: 10,
    totalRows: 100,
    className: "w-full min-w-80",
  }}
/>

```tsx
<DataTablePagination
  rowsPerPage={10}
  totalRows={100}
  onChange={(page, start, end) => fetchPage(page)}
/>
```

### Usage

**Data Table Pagination does not manage the data of the table.** You can use the
`rowsPerPage` and `totalRows` props to control the pagination, and use the
`onChange` prop to trigger the logic for fetching the next page of data when the
user changes the page.

**With Tanstack Table**, you can hook up the `onChange` function to
`setPageIndex` to fetch the next page of data.

```tsx
<DataTablePagination
  rowsPerPage={10}
  totalRows={100}
  onChange={(newPage) => setPageIndex(newPage - 1)}
/>
```

> The first page is 1, but Tanstack Table uses 0-based indexing, so we need to
> **subtract 1 from the new page number** when calling `setPageIndex`.
>
> ```txt
>  SK Components: 1, 2, 3, 4, 5, ...
> Tanstack Table: 0, 1, 2, 3, 4, ...
> ```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.

<PropsTable>
  <PropsTableRow prop="rowsPerPage" required="always">
    <TableCell>`number`</TableCell>
    <TableCell>

      The maximum number of rows shown on the Data Table at a time.

      - Must be a non-negative integer.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="totalRows" required="always">
    <TableCell>`number`</TableCell>
    <TableCell>

      The total number of rows of data, including both those currently shown and
      not shown on the Data Table.

      - Must be a non-negative integer.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the page indicator and accessibility labels.

      - Must be `"en-US"` or `"th"`, as SKCom currently only support those 2
        languages.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="onChange" required="never">
    <TableCell>`(page: number, start: number, end: number) => any`</TableCell>
    <TableCell>

      Triggers when the user changes the page.

      - The following is passed onto the function: the current page number, the
        start index, and the end index.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
