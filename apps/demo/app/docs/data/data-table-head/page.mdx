## Data Table Head

The head area of a Data Table.

<LinksChipSet source="/DataTableHead.tsx" />

```tsx
<DataTableHead headerGroups={table.getHeaderGroups()} colSpans={[1, 2, 1]} />
```

### Props

- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.

<PropsTable>
  <PropsTableRow prop="headerGroups" required="always">
    <TableCell>`HeaderGroup<any>[]`</TableCell>
    <TableCell>

      The return of `getHeaderGroups`, one of the functions of the Tanstack Table
      instance.

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="align" required="never">
    <TableCell>
      ```
      "left"
      | "center"
      | "right"
     ```
     </TableCell>
    <TableCell>

      How the content in each cell should be positioned. It can be aligned to the
      left, the center (default), or the right.

      - Must be `left`, `center`, `right`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="colSpans" required="never">
    <TableCell>`number[]`</TableCell>
    <TableCell>

      The fractional width of each column, in the same order as the columns are
      defined.

      - Must be an array of numbers.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="locale" required="never">
    <TableCell>`"en-US" | "th"`</TableCell>
    <TableCell>

      Allows for translation of the accessibility labels.

      - Must be `th` or `en-US`, as SKCom currently only supports these two
        languages.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
