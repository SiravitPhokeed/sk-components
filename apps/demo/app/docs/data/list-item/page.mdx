An item inside a List.

```tsx
  <img src="/images/pork-burger.png" alt="Pork Burger" />

```

### Props

- [`ActionableProps`](/docs/guides/shared-props) available: `command`,
  `commandfor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The content of a List Item consists of the leading section, the content
      section, and the trailing section.

      - Any components placed before List Item Content is put into the leading
        section, and any after is put into the trailing section.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="align" required="always">
    <TableCell>`"top" | "center" | "bottom"`</TableCell>
    <TableCell>

      The vertical alignment of the List Item’s content.

      - Must be `top`, `center`, or `bottom`.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="lines" required="always">
    <TableCell>`1 | 2 | 3 | [1\|2\|3, 1\|2\|3, 1\|2\|3, 1\|2\|3]`</TableCell>
    <TableCell>

      The number of lines contained by the List Item. The height is set from
      this prop.

      - Must be an integer (or a list of 4 integers, each corresponding to a
        breakpoint) from 1 to 3.
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="stateLayerEffect" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      A state layer is a visual overlay that responds to user interaction. For
      example, a Button’s state layer increases its opacity on hover, signaling
      it’s clickable.

      - This effect can be enabled on List Item too, helping users recognize
        it as interactive.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="containerElement" required="never">
    <TableCell>`ElementType`</TableCell>
    <TableCell>

      The element to use as the container of the List Item.

      - Defaults to `<li>`.
      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
