## Assist Chip

Assist Chips are similar to [Buttons](/docs/inputs/button) in that they help users take action. The
difference is a Button is persistent (doesn’t change) and an Assist Chip is
dynamic and contextual (changes according to the context).

Assist Chips appear in a [Chip Set](/docs/data/chip-set).


### Usage

The label of an Assist Chip should start with a verb, i.e. “_Turn on_ lights” or
“_Save_ to favorites.”

<ChipSet className="my-3">
  <AssistChip
    children="Turn on lights"
    icon={<MaterialIcon icon="lightbulb" />}
  />
  <AssistChip
    children="Save to favorites"
    icon={<MaterialIcon icon="bookmark" />}
  />
</ChipSet>

### Props

- [`ActionableProps`](/docs/guides/shared-props) available: `command`,
  `commandfor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The text shown inside the Assist Chip.

      - The label should start with a verb, i.e. “_Turn on_ lights” or “_Save_
        to favorites.”
      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="icon" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon can appear before the text in an Assist Chip. In a Chip Set with
      many chips, an icon can help the user find the right one more quickly.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as the value for `icon`.
      - Favicons and branded icons can also be used here.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="tooltip" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A message shown in a tooltip when the user hovers over the Assist Chip.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="elevated" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Use elevation instead of an outline to signify the Assist Chip’s boundary.

      - **Use sparingly.** Only elevate an Assist Chip when its placement
        requires visual protection, such as on top of an image.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="dangerous" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      If the action the Assist Chip accomplishes is dangerous, like deleting
      your account. If it is, the Assist Chip turns red (defined as `error` in
      the palette).

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="loading" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Disable the Assist Chip to signify loading status. `onClick` and `href`
      will have no effect.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Turns the Assist Chip gray and blocks any action associated with it.
      `onClick` and `href` will have no effect.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
