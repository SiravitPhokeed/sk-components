## Material Icon

Icons are essential to any web design. They orient the users, help user
navigate, and save space. Material Icon uses the “Material Symbols Outlined”
icon font from Google.

```tsx
<MaterialIcon size={48} icon="person" />
```

You can find the list of all icons at
[Google Fonts](https://fonts.google.com/icons).

### Usage

**Fonts are not bundled with the library, so you need to include the Material
Symbols Outlined font in your project.** Follow the instructions in the
[getting started](/docs/guides/getting-started) guide.

Material Icon uses `font-variation-settings` to adjust the icon’s weight, grade,
and size. You can **use `font-variation-settings` to your `transition` property
to animate** the icon’s weight, grade, and size.

### Props

- `StyleableProps` are available: `className` and `style`.

  <PropsTableRow prop="fill" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      If the icon is filled or not.

      - An icon should be outlined by default, filling it should have a specific
        meaning, like if a Navigation Bar Item is selected.
      - Uses the `FILL` font variation setting on the Material Symbol font.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="weight" required="never">
    <TableCell>

    100

    | 300
    | 400
    | 500
    | 600
    | 700
    ```
    </TableCell>
    <TableCell>

      How thick the strokes are.

      - Keep the weight consistent throughout an application. Hovering/focusing
        can affect the weight, however.
      - Uses the `wght` font variation setting on the Material Symbol font.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="grade" required="never">
    <TableCell>
    ```
    -25

    </TableCell>
    <TableCell>

      `grade` also adjusts the icon’s thickness, but more subtly.

      - A lower grade is used in light icons on a dark background. A higher

      - Uses the `GRAD` font variation setting on the Material Symbol font.
      - Optional.

      </TableCell>

  </PropsTableRow>
