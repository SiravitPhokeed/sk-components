## Interactive

Indicates interactivity with a state layer and a ripple effect.

<LinksChipSet source="/Interactive.tsx" />

<DemoCard
  component={Interactive}
  initialProps={{
    children: (
      <>
        <Text type="title-medium">English</Text>
        <Text type="body-small">Phubodin</Text>
      </>
    ),
    element: "button",
    className:
      "bg-secondary-container text-on-secondary-container state-layer-on-secondary-container grid h-14 w-24 rounded-sm px-4 py-2 text-start",
  }}
  adjustableProps={{
    stateLayerEffect: "boolean",
    rippleEffect: "boolean",
    shadowEffect: "boolean",
  }}
>
  `stateLayerEffect` and `rippleEffect` are enabled by default. Double-click to
  disable.
</DemoCard>

```tsx
<Interactive shadowEffect className="...">
  <Text type="title-medium">English</Text>
  <Text type="body-small">Phubodin</Text>
</Interactive>
```

### Props

- `ComponentProps<"div">` are available: all props of a `<div>` element.
- `ActionableProps` are available: `command`, `commandFor`, `onClick`, and `href`.
- `StyleableProps` are available: `className` and `style`.
- `ElementCustomizableProps` are available: `element`.

  <PropsTableRow prop="children" required="always">

  <PropsTableRow prop="rippleEffect" required="never">
    <TableCell>`boolean`</TableCell>

      Show an ink ripple effect, a soft-edge translucent circle, radiating out
      of the click/tap position every click/tap to signify interactivity.

      - Enabled by default.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="shadowEffect" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      - Optional.

      </TableCell>

  </PropsTableRow>
