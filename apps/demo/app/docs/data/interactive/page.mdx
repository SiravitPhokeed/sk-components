## Interactive

Indicates interactivity with a state layer and a ripple effect.

<LinksChipSet source="/Interactive.tsx" />

<DemoCard
  component={Interactive}
  initialProps={{
    children: (
      <>
        <Text type="title-medium">English</Text>
        <Text type="body-small">Phubodin</Text>
      </>
    ),
    element: "button",
    className:
      "bg-secondary-container text-on-secondary-container state-layer-on-secondary-container grid h-14 w-24 rounded-sm px-4 py-2 text-start",
  }}
  adjustableProps={{
    stateLayerEffect: "boolean",
    rippleEffect: "boolean",
    shadowEffect: "boolean",
  }}
>
  `stateLayerEffect` and `rippleEffect` are enabled by default. Double-click to
  disable.
</DemoCard>

```tsx
<Interactive shadowEffect className="...">
  <Text type="title-medium">English</Text>
  <Text type="body-small">Phubodin</Text>
</Interactive>
```

### Usage

Interactive adds a state layer and optional ripple effect to any element. Use
Tailwind CSS classes to style the state layer color.

```tsx
<Interactive
  shadowEffect
  element="button"
  className="bg-secondary-container text-on-secondary-container state-layer:bg-on-secondary-container h-14 rounded-sm px-4 py-2"
>
  <Text type="title-medium">English</Text>
  <Text type="body-small">Atipol</Text>
</Interactive>
```

### Props

- `ComponentProps<"div">` are available: all props of a `<div>` element.
- [`ActionableProps`](/docs/guides/shared-props) available: `command`,
  `commandfor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props) available: `className` and
  `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props) available: `element`.
