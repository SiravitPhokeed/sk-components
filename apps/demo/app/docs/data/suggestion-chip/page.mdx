## Suggestion Chip

Dynamically generated suggestions, such as quick-reply options.

  material="/components/chips/guidelines#36d7bb16-a9bf-4cf6-a73d-8e05510d66a7"

/>

```tsx
<SuggestionChip icon={<MaterialIcon icon="thumb_up" />}>
  Looks good to me
</SuggestionChip>
```

### Props

- [`ActionableProps`](/docs/guides/shared-props): `command`, `commandFor`, `onClick`, and `href`.
- [`StyleableProps`](/docs/guides/shared-props): `className` and `style`.
- [`ElementCustomizableProps`](/docs/guides/shared-props): `element`.

<PropsTable>
  <PropsTableRow prop="children" required="always">
    <TableCell>`ReactNode`</TableCell>
    <TableCell>

      The text shown inside the Suggestion Chip.

      - Always required.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="icon" required="never">
    <TableCell>`ReactElement`</TableCell>
    <TableCell>

      An icon can appear before the text (`children`) in a Suggestion Chip. In
      a Chip Set with many chips, an icon can help the user find the right one
      more quickly.

      - You are encouraged to use [Material Icon](/docs/data/material-icon) as the value for `icon`.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="tooltip" required="never">
    <TableCell>`string`</TableCell>
    <TableCell>

      A message shown in a tooltip when the user hovers over the Suggestion
      Chip.

      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="elevated" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Use elevation instead of an outline to signify the Suggestion Chip’s
      boundary.

      - **Use sparingly.** Only elevate a Suggestion Chip when its placement
        requires visual protection, such as on top of an image.
      - Optional.

      </TableCell>

  </PropsTableRow>

  <PropsTableRow prop="disabled" required="never">
    <TableCell>`boolean`</TableCell>
    <TableCell>

      Turns the Suggestion Chip gray and blocks any action associated with it.
      `onClick` and `href` will have no effect.

      - Optional.

      </TableCell>

  </PropsTableRow>
</PropsTable>
