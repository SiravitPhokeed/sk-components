## Using with Tailwind CSS v4

Integrate [Tailwind CSS](https://tailwindcss.com/) with SK Components to use
utility classes in your project.

<TailwindSelector value="v4" />

### Layers

All styles in SK Components are declared under the `@layer skc` directive. To
use SK Components with Tailwind CSS v4, you need to add this line **before** the
`@import` directive in your Tailwind CSS configuration file.

```css title="globals.css" {1} "skc"
@layer theme, base, skc, components, utilities;
@import "tailwindcss";
```

Using layers means that you can use utility classes to override SK Components
styles without needing `!important`.

```tsx {1} "bg-tertiary text-on-tertiary"
<Button appearance="filled" className="bg-tertiary text-on-tertiary">
  Tertiary button
</Button>
```

### Theme

To use the variables provided by [Theme Provider](/docs/layout/theme-provider)
with Tailwind CSS (e.g. `bg-primary`), you need a translation layer between the
two. This is done by declaring [theme
variables](https://tailwindcss.com/docs/theme) in your global CSS file pointing
to the CSS variables provided by Theme Provider.

You can also [declare the theme in a separate CSS
file](https://tailwindcss.com/docs/theme#sharing-across-projects) and import it.

> Make sure you **use
> [`@theme inline`](https://tailwindcss.com/docs/theme#referencing-other-variables)
> rather than plain `@theme`.** The `inline` variant tells Tailwind to reference
> your CSS variables directly instead of generating new ones. This is necessary
> because Theme Provider already defines the variables at runtime.

The configuration below maps SKCom’s CSS variables to Tailwind’s design tokens.

### State layer

Components that use state layers and ripple effects (e.g. Buttons, Chips, etc.)
can have those elements customized with Tailwind CSS utilities.

[`@utility`](https://tailwindcss.com/docs/adding-custom-styles#adding-custom-utilities)
lets you define custom utility classes in Tailwind v4. The snippet below
registers a `state-layer-*` utility that accepts any Tailwind color token.

```css title="globals.css"
@utility state-layer-* {
  --state-layer-color: --value(--color-*);
}
```

```tsx {1} "state-layer-primary"
<Interactive className="state-layer-primary">
  I have a primary state layer!
</Interactive>
```

Now the state layer and ripple effect will use the `primary` color.
