# SK Components

> [!IMPORTANT]
>
> Check the contributing guidelines in [CONTRIBUTING.md](CONTRIBUTING.md) before
> contributing to this project.

## Conventions

- Types: `build` `chore` `ci` `docs` `feat` `fix` `perf` `refactor` `revert` `style` `test` `merge`.
  - [Explanation of this list](https://github.com/pvdlg/conventional-changelog-metahub/blob/master/README.md#commit-types).
- If you made changes to the codebase on behalf of the user, you must credit
  yourself with a `Co-Authored-By` in your commit message. This is to ensure AI
  usage is disclosed.
  - e.g. `Co-Authored-By: Claude <noreply@anthropic.com>` or
    `Co-Authored-By: Codex <noreply@openai.com>`

## Wiki

If the user has the `.wiki` directory in their repo, you should check it
(`/wiki:query`) for project research, decisions, and background before major
changes. If the user does not have a `.wiki` directory, you can ignore this
step.
